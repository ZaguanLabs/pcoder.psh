# pcoder.psh v0.25.0 — Faster edits in long conversations

Paste a few thousand lines of code, edit a long prompt, or send the next turn in a large Ollama conversation. Those are the three places where v0.25.0 cuts the most waiting. The changes use the array, string, and display-width operations already in psh.

| Operation | Before | After |
| --- | ---: | ---: |
| Normalize a paste of 2,048 tab-indented lines with CRLF endings | 79.81 ms | 4.56 ms |
| Append a character to a 100,000-character ASCII line, including terminal redraw | 19.51 ms | 1.42 ms |
| Build an Ollama request with 1,000 ordinary messages of 1 KiB each | 15.94 ms | 8.29 ms |

These are median workstation timings on psh 1.0.0-rc3. Each row compares the code immediately before and after its optimization. Request timings cover local preparation and exclude network and model time. [Measurements and reproduction instructions](https://github.com/ZaguanLabs/pcoder.psh/blob/v0.25.0/docs/psh-rc3-profile.md)

### What changed

- **Editing and paste.** Moving the caret reuses the existing line layout. Typing near the end of a draft rewraps the affected rows. Long Unicode lines are measured in spans, with character-level checks at row boundaries for wide glyphs and combining marks. Native paste normalization preserves indentation and trailing blank lines.
- **Streaming.** Updating a live Markdown reply reuses the preceding transcript layout. With 1,000 earlier messages, a preview update fell from 3.43 to 2.05 ms with terminal writes mocked. The HTTP parser also consumes whole socket reads directly when they fit inside the response body.
- **Conversation history.** Records ready for Ollama can be joined in one operation. Saved system-role messages from older sessions still get normalized. A tool argument named `input_id` now survives when a message also carries a local queue receipt.

### Run from source

Use psh 1.0.0-rc2 or newer with its bundled zjson, zdraw, and zmdown components. Download either source archive and `SHA256SUMS` from this release. For the tarball, run these commands from the download directory on Linux with psh and Make installed.

```sh
sha256sum --check --ignore-missing SHA256SUMS
tar -xzf pcoder.psh-0.25.0.tar.gz
cd pcoder.psh-0.25.0
make compile
./pcoder.psh --version
```

To start a conversation, point pcoder at your workspace and a tool-capable model available on your Ollama server. [Quick start](https://github.com/ZaguanLabs/pcoder.psh/blob/v0.25.0/README.md#try-it)
